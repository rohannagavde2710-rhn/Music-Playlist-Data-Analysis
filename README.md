# Music Store Data Analysis using MySQL

## Project Overview
This project analyzes music store data using MySQL.
It focuses on SQL queries to retrieve, organize, and analyze
data from seven existing tables.

## Database Tables
1. employee
2. album
3. artist
4. genre
5. invoice
6. playlist
7. track

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- Self JOIN
- Subqueries
- COUNT()
- SUM()
- AVG()
- ROUND()

## Analysis Performed
- Invoice count by country
- Revenue analysis by city
- Top 10 Rock artists by track count
- Tracks longer than average song length
- Genre-wise track count
- Album-wise track count
- Artist-wise album count
- Employee and manager analysis

## Tools Used
- MySQL
- MySQL Workbench
